## Problem
40M+ traders in Northern Nigeria cannot use English accounting apps. They lose profit, forget debts, can't market. Low literacy + Hausa language = excluded from fintech.

## Solution: ArewaMoney AI
Voice-first AI agent for Hausa traders. Trader speaks in Hausa: "Na sayi takalmi 20 akan 1500 na sayar 2500"

1.  **Muse Spark STT** -> Transcribes Hausa voice note from WhatsApp
2.  **Llama 3.3 70B (Meta Model API)** -> Extracts transaction: Buy 20 shoes @1500, Sell @2500
3.  **Auto-calc Engine** -> Profit = 20,000 Naira, updates ledger
4.  **SAM 3.1 + Muse Image** -> Generates MAMMAN MILLION sales poster with price tag
5.  **WhatsApp Cloud API** -> Sends daily report in Hausa: "Yau ka samu riba N20k"

No app needed. Works on 2G. Voice only.
